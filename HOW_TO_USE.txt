REDSTORE IMAGE ORGANIZATION
============================

This package is a safe organizer for your existing RedStore project.

What it does:
1. Creates an "images" folder.
2. Moves root-level image files (.png/.jpg/.jpeg/.webp/etc.) into images/.
3. Updates HTML/CSS image paths automatically:
      logo.png
   becomes:
      images/logo.png
4. Removes .DS_Store from the project root.
5. Does NOT delete your HTML/CSS files.

HOW TO USE ON MAC
-----------------

Option A — easiest:
1. Put "organize_redstore.py" inside your RedStore project folder.
2. Double-click "organize_redstore.command".
3. If macOS blocks it, open Terminal and run:
      chmod +x organize_redstore.command
   then:
      ./organize_redstore.command

Option B — Terminal:
1. Put organize_redstore.py inside your RedStore folder.
2. Open Terminal.
3. cd into the RedStore folder.
4. Run:
      python3 organize_redstore.py

IMPORTANT
---------
Make a backup/copy of the RedStore folder first.

After it finishes:
1. Open index.html in your browser.
2. Check Product, Product Detail, Account and Cart pages.
3. Confirm all images appear.
4. Then push the changes to GitHub.

Git commands:
    git add .
    git commit -m "Organize website images"
    git push

The final structure should look like:

RedStore/
├── index.html
├── product.html
├── product-detail.html
├── account.html
├── cart.html
├── style.css
├── README.md
└── images/
    ├── logo.png
    ├── cart.png
    ├── category-1.jpg
    ├── category-2.jpg
    ├── category-3.jpg
    └── ...all other website images...
